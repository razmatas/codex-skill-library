# Brand Inspo Reference

Use Rebrand.gallery, Branding Website, and BRRRANDING as complementary identity-reference sources. Translate research into an original, actionable brand direction; when Figma is requested, make the delivered board a rich visual record of the references rather than a text-heavy analysis.

## Establish the brief

Capture the product, audience, category, desired mood, existing brand constraints, and any colour or type preferences. Inspect supplied brand material first; those constraints are authoritative.

Research each source for what it exposes best:

- **Rebrand.gallery:** rebrand launches, identity systems, reveal videos, and individual touchpoints such as brand guidelines, packaging, signage, editorial, stationery, merch, and motion. Filter by industry, style, typography, colour family, or feel. Use an authenticated browser session when the user has access to gated content.
- **Branding Website:** broad visual-identity examples with filters for colour, style, typeface, and industry. Use it to widen the stylistic range of a shortlist and identify relevant studios or creators.
- **BRRRANDING:** curated projects searchable by industry, year, colour, elements, and type. Use it when the brief calls for a specific expression such as custom type, packaging, motion, website, app, environmental graphics, print, or a new brand versus a rebrand.

## Build the direction

Select a small, varied reference set—usually three to five entries across the galleries—and extract only transferable decisions:


- colour roles and contrast;
- typography pairing and hierarchy;
- logo and graphic-device character;
- art direction for photography, illustration, texture, and motion; and
- touchpoint treatment across the brand system.

Credit every retained reference by brand/studio name and canonical link. Never present a reference’s logo, proprietary media, or copy as original work. Make a clear recommendation for one coherent creative direction rather than combining all reference traits.

## Figma reference boards

When the user asks to place inspiration in Figma, produce a media-first reference board. The point is to let the user see the actual identity work, not to read a summary of it.

- Give every selected brand its own top-level Figma frame/canvas. Name it clearly with the brand and source.
- Populate that frame with a dense, deliberate mosaic of the source material available to the user: identity reveals, logo and wordmark applications, typography in use, colour and graphic systems, websites/apps, packaging, editorial, environments, merchandise, and campaign work. Prefer original stills, GIFs, and motion/video keyframes over recreated swatches or generic placeholders.
- Use enough varied visual material to reveal the system—normally at least six assets per brand when the source exposes them. Preserve the source media’s aspect ratio and avoid decorative cropping that obscures the work.
- Add only a small supporting layer: brand/studio, canonical source link, and concise labels where needed to identify a visual, typeface, or colour value. Let the imagery dominate the canvas.
- Capture exact type names, colour values, and motion notes only when visibly stated by the source. If they cannot be verified, label them as an inference or omit them.
- Import actual source assets into Figma only after the user has asked for a Figma deliverable and supplied an editable destination. Keep attribution close to the relevant board and retain the canonical links.
- If a source exposes video but the target cannot host it natively, use an available GIF or representative keyframes and retain the original video link. Do not replace source media with generated imitations.

Do not mix several brands into a single generic insight canvas unless the user explicitly asks for a comparative board. A small final synthesis/recommendation frame is optional; it should never displace the per-brand visual boards.

## Access boundaries

These galleries do not have connected MCP tools in this environment. Research public pages through web browsing. For a paid Rebrand.gallery account, ask the user to sign in themselves in the browser session and confirm it is ready; never request credentials, passwords, or authentication codes. Do not assume a separate browser or connector shares that signed-in session. If an asset is not available in that authenticated session or cannot be imported, retain its link rather than bypassing access controls.
